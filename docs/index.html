The release workflow

Check what each URL does.

Decide what should stay in search, what should redirect, and what should stay out. The skill compares that intent with staging and gives you a Pass, Block, or Unverified decision for the routes you checked.

Read the skill ↗
Redirects and missing pages
Check the destination, preserve campaign parameters, and catch a missing page that returns 200.
Canonicals and crawl access
Compare HTTP and HTML canonicals. Check which robots.txt rule applies to Googlebot and which directives it can read.
What changes in the browser
Compare the served head with the rendered DOM. See when JavaScript rewrites a canonical or adds noindex.
Sitemaps and sharing images
Verify the URLs in the leaf sitemap and check what the declared share image actually serves.
